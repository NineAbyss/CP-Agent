# Test-Augmentation Diagnostics

This analysis evaluates whether Test Augmentation (TA) provides useful
candidate-level evidence beyond public tests. To avoid circular validation, the
augmented tests were generated by CP-Agent with the DeepSeek-V3.2-Chat backbone,
while the evaluated candidate solutions were produced independently by
DeepSeek-V3.2 Reasoner on the same LCB-Pro problems.

## TA Label Accuracy

The diagnostic pool contains 117 problems where TA successfully generated
augmented tests and the candidate solution had already passed all public tests.
Among them, 51 candidates are actually incorrect and 66 are actually correct
according to the online judge. A positive prediction means the augmented tests
flag the candidate as buggy.

| Ground Truth | Predicted Buggy (Fail TA) | Predicted Correct (Pass TA) | Total |
|---|---:|---:|---:|
| Actually incorrect | TP = 40 | FN = 11 | 51 |
| Actually correct | FP = 19 | TN = 47 | 66 |
| Total | 59 | 58 | 117 |

| Metric | Formula | Value |
|---|---|---:|
| Accuracy | `(TP + TN) / All` | `87 / 117 = 74.4%` |
| Precision | `TP / (TP + FP)` | `40 / 59 = 67.8%` |
| Recall | `TP / (TP + FN)` | `40 / 51 = 78.4%` |
| F1 | `2PR / (P + R)` | `72.7%` |
| Specificity | `TN / (TN + FP)` | `47 / 66 = 71.2%` |
| FPR | `FP / (FP + TN)` | `19 / 66 = 28.8%` |
| FNR | `FN / (TP + FN)` | `11 / 51 = 21.6%` |

Although TA is an imperfect verifier, it improves accepted-set quality in this
diagnostic pool. Before TA filtering, the hidden-bug rate is `51 / 117 = 43.6%`.
Among candidates that survive TA, the hidden-bug rate drops to
`11 / 58 = 19.0%`, so the post-survival correctness rate is `47 / 58 = 81.0%`.

## Test-Case Diversity

We estimate diversity by randomly sampling `k` generated test cases from each TA
suite and measuring whether at least one sampled case exposes the incorrect
candidate. The evaluation is conducted on the 51 actually incorrect candidates
from the diagnostic pool. Results are mean +/- standard deviation over 100
random draws.

| k sampled cases | Bug detection rate |
|---:|---:|
| 1 | `37.6% +/- 5.8%` |
| 2 | `51.4% +/- 5.1%` |
| 3 | `58.9% +/- 4.4%` |
| 5 | `65.7% +/- 3.3%` |
| 9 | `70.0% +/- 2.0%` |
| 15 | `74.5% +/- 0.8%` |

The detection rate rises steadily with `k`, indicating that TA-generated cases
cover complementary failure modes rather than only duplicating the same signal.
